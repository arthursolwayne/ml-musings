# Bits per chunk

## Empirical anchors

Binary digit: 1 bit
Decimal digit: 3.3 bits (log₂10)
Letter: 4.7 bits (log₂26)
Monosyllabic word: ~10 bits
Common word: ~13 bits (log₂ of ~10k vocabulary)

## Lower bound

1 bit. Binary digit, no associations.

## Upper bound

A chunk is a pointer to long-term memory. "E=mc²" is one chunk if you know physics but decompresses to unlimited info.

Pointer size: ~10⁷-10⁹ known concepts/patterns. log₂(10⁹) ≈ 30 bits to address any chunk.
Decompressed content: unbounded, but retrieved from LTM, not held in WM.

## Estimate

Lower: 1 bit
Typical: 3-15 bits
Upper (pointer): ~30 bits
